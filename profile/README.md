## Holy Lois: Reborn

A small Minecraft survival server for a group of friends: Fabric 26.3, a curated modpack and a one-click Windows launcher.

- Website, guide and rules: [holylois.com](https://holylois.com)
- Live map: [map.holylois.com](https://map.holylois.com)
- Discord: [holylois.com/discord](https://holylois.com/discord)

| Repository | What |
| --- | --- |
| [HLMC-Reborn](https://github.com/holylois/HLMC-Reborn) | The modpack channel, player and admin guides, rules and server tools |
| [HLMC-Reborn-Packaging-Lab](https://github.com/holylois/HLMC-Reborn-Packaging-Lab) | The Holy Lois launcher and the server/client add-ons |

The launcher has no code-signing certificate, so Windows may warn before the first start.
